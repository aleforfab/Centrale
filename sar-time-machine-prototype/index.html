How it works

  1. Backend publishes an ordered list of dated, coregistered layers.
  2. Frontend preloads frames, then crossfades between dated frames—no invented intermediate data.
  3. Swipe clips one fixed frame over another; it does not warp the imagery.
About the synthetic frames

The island grows radially and a bright flow extends south-east. Speckle is deterministic per frame. Gaps between dates are irregular (4–21 days) to mirror a real 12-day stack with missed passes.

To regenerate the PNGs on disk: python synthetic.py --output frames/
